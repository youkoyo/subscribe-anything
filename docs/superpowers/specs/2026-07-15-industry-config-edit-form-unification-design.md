# 产业信息配置编辑表单统一设计

## 背景

`新建产业信息` 页面已经提供以自然语言、信息源偏好和逐步披露设置为主的简化体验。信息池中的“编辑产业配置”弹窗仍使用旧的全量字段表单，因而在字段、层级和默认值上与新建页分叉。

## 目标

以新建页为唯一的表单交互基准：新建与编辑均使用同一套字段、分组、来源偏好和投递选项。保留信息池内的弹窗编辑入口，不改变管理员的操作路径。

## 方案

1. 提取一个可复用的产业配置表单组件，负责字段展示、表单状态、来源预览和客户端校验。
2. 新建页使用空白默认状态，提交后保留现有的创建并进入构建流程的行为。
3. 编辑弹窗使用同一组件并以已存储的配置预填；提交后保留现有的更新、重新加载和提示行为。
4. 只传递共享表单中可编辑的字段。旧配置中未展示的关键词、风险词、区域、对象、源类型、关注级别、报送 Cron 和时区必须在更新时保留原值，不能因为隐藏而被清空。

## 共享字段与层级

- 必填：产业名称。
- 可选：关注方向。
- 常显：信息源偏好。
- 可展开：行业分类、细分领域。
- 可展开：邮件报送开关、允许用户补充需求。
- 保留现有右侧构建预览；在弹窗中以适合窄容器的单列布局呈现同一信息。

## 兼容性与错误处理

编辑初始状态要将已存储的 `sourcePreferences` 还原到共享表单；对旧数据缺少该值的情况，使用与新建页一致的默认偏好。名称为空时阻止提交并显示错误；来源匹配预览失败不影响保存。

## 验证

1. 新建页和编辑弹窗显示同一组字段与分组。
2. 打开现有产业配置时，名称、关注方向、分类、偏好和开关可正确回显。
3. 保存编辑后，隐藏的旧字段值保持不变。
4. 编辑成功后列表数据刷新，并保留现有的提示与错误反馈。

## 非目标

不调整后端的产业配置数据模型，不迁移编辑入口到独立页面，不改变投递调度规则。
