# 实时产业新闻检索可靠性设计

## 目标

当用户订阅“近期国内鞋业相关新闻资讯”时，系统应能从可持续更新的国内新闻入口发现并采集“晋江鞋厂火灾”这类近期重大事件，而不是仅返回海外行业站、泛财经流或过期专题页。

## 方案

### 统一网页解码

新增共享响应解码器。它优先使用 HTTP `charset`，缺失时扫描 HTML 的 `meta charset`；`gbk` 和 `gb2312` 统一映射到 `gb18030`。调研工具 `webFetch` 与沙箱 `fetch().text()` 必须共用它，保证 AI 看到的列表内容和脚本运行时看到的内容一致。

### 发现源组合验收

当条件包含“国内”时，发现结果必须有 5 至 10 个候选，至少一个国内综合或地方新闻源、至少一个国内行业垂直源，财经推荐最多一个。每个推荐源还必须有预检索中的近期同域证据；不满足时不得记录为发现成功，而是要求智能体补足候选。

### 脚本生成与验证

脚本只能基于调研阶段实际观察到的列表链接和字段生成，禁止猜文章 ID。验证样本必须含近期、条件匹配的内容；连续三次失败直接停止并报告真实原因。对 GBK 页面，应能从首页的真实链接和标题中解析近期中文新闻。

## 验收

- 用 GBK 编码的福建中新网首页夹具，调研输出及沙箱输出均能识别“福建晋江一鞋厂火灾已致28人死亡”。
- “近期国内鞋业相关新闻资讯”的发现结果不接受只有海外或台湾行业站的 3 条列表。
- 泉州/晋江等实际列表页中的近期火灾链接可作为采集样本通过质量审查。
